# Files

- [KiyoAutofill Web Contract](kiyautofill.md) - Web-side TypeScript contract for KiyoAutofill plugin (autofill status, sync, settings).
- [KiyoFile Capacitor Plugin](kiyofile.md) - Capacitor plugin for file system operations (save, open, read, write) with web fallbacks for vault import/export functionality.
- [KiyoSecureKey Web Contract](kiyosecurekey.md) - Web-side TypeScript contract for biometric vault unlock plugin (storeKey, unlockKeyWithBiometric, hasKey, deleteKey, isBiometryAvailable).
