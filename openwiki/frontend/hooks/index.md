# Files

- [useAndroidBackButton Hook](use-android-back-button.md) - A React hook that handles Android hardware back button presses using Capacitor's App plugin, navigating back in history or exiting the app.
- [useAutoLock Hook](use-auto-lock.md) - A React hook that manages the auto-lock timer with activity detection for KIYO vault sessions.
- [useClipboard Hook](use-clipboard.md) - A React hook for copying text to the clipboard with feedback on copy state and duration.
- [useFileAuthGuard Hook](use-file-auth-guard.md) - A React hook that guards routes based on file authentication status in KIYO.
