# Files

- [Account Model](account.md) - Frontend Account model. Represents a single password/account entry with custom fields defined by templates.
- [Field Types Model](fieldTypes.md) - FieldType union used by AccountField and TemplateField.
- [Models Overview](overview.md) - TypeScript type definitions for vault, account, template, and supporting data structures.
- [Template Model](template.md) - Defines a reusable field set used to scaffold new accounts.
- [Vault Model](vault.md) - Represents the snapshot of accounts/templates/metadata that is encrypted into the file record and decrypted back into stores on unlock.
- [WebsitePreset Model](websitePreset.md) - Defines presets for automatic matching of accounts to websites/apps based on domain or package name.
