# KIYO — Hermes Project Context

## Project Overview
**KIYO** — Offline-first, privacy-focused Android password manager with system-level autofill.
- 로컬 암호화 저장 (PBKDF2 100k + AES-GCM)
- Android AutofillService (API 26+)로 앱/웹 자동완성
- 네트워크 권한 없음, 클라우드 동기화 없음, 모든 데이터 로컬 저장
- 다중 암호화 볼트 생성/가져오기/백업/복원 지원
- **Android Keystore 연동** — `kiyo_master_key`(autofill DB) / `kiyo_secure_master_key`(biometric vault) 별도 보호
- **자동 잠금** — `none` / `1m` / `10m` / `30m` (활동 감지 시 리셋, 키 상실 시 즉시 잠금)

## Tech Stack
| Layer | Technologies |
|-------|--------------|
| Frontend | React 19, TypeScript, Vite, Tailwind CSS 4, Zustand, React Router 7 |
| Native Bridge | Capacitor 8 (Android) |
| Local DB | Dexie.js (IndexedDB) |
| Crypto | Web Crypto API (PBKDF2 + AES-GCM) |
| Android Native | Kotlin, AutofillService, SQLiteOpenHelper, Android Keystore, DataStore |
| Testing | Vitest (unit/integration) |

## Architecture
```
React App (WebView) ◄──Capacitor Bridge──► Android Native (AutofillService)
       │                                           │
       ▼                                           ▼
  IndexedDB (Dexie)                          SQLCipher DB (Autofill Repo)
       │                                           │
       ▼                                           ▼
  암호화 JSON (PBKDF2+AES)                    DB_KEY (AES-256, SQLCipher)
                                                    │
                                                    ▼
                                         Android Keystore
                                         ├─ kiyo_master_key (autofill)
                                         └─ kiyo_secure_master_key (biometric)
```

## Key Components
| Component | Role |
|-----------|------|
| React App | UI, 계정 관리, 설정, 암호화/복호화 |
| KiyoAutofillPlugin | React ↔ Native 브리지 |
| KiyoAutofillService | 시스템 자동완성 제공 (필드 탐지, 매칭, FillResponse) |
| KeystoreManager / DatabaseKeyManager | `kiyo_master_key` 관리, DB_KEY 래핑/언래핑 (DataStore) |
| SecureKeyManager / BiometricAuthHelper / SecureKeyPlugin | `kiyo_secure_master_key` 관리, 생체인증 볼트 언락 |

## Critical Conventions
- **TypeScript strict**, ESM only, `@/` → `src/`, React 19
- **NEVER persist encryption keys to disk** — keys in `SecuritySession` (memory) only
- PIN → PBKDF2 (100k) → AES-GCM; 레코드 단위 암호화 (Account/Template 직렬화)
- `syncAutofillToken()` deprecated/no-op — Autofill은 순수 Keystore 기반 인증만 사용
- **Android 변경 후 `npx cap sync android` 필수**
- **Main branch: `v2`**, conventional commits

## Data Storage & Security
| 데이터 | 저장소 | 암호화 | 비고 |
|--------|--------|--------|------|
| 메인 계정 | 파일 시스템 (Documents) | AES-GCM (PIN 기반) | 백업/이동 가능 |
| 자동완성 계정 | SQLite (Native) | SQLCipher + Keystore | AutofillService 전용 |
| IndexedDB 계정 | IndexedDB (Dexie) | AES-GCM 레코드 단위 | 전체 객체 암호화 |
| 앱 설정 | IndexedDB (Dexie) | 평문 | 테마, 폰트 등 |
| `kiyo_master_key` | Android Keystore | 하드웨어/TEE | autofill DB_KEY 보호 |
| `kiyo_secure_master_key` | Android Keystore | 하드웨어/TEE | biometric vault 키 보호 |

5. **Pipeline functions 사용**: `createEncryptedVault`, `persistVaultRecord`, `setupVaultSession`, `exportVaultFile`
